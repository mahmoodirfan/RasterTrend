# Contributing to RasterTrend

Thank you for helping improve RasterTrend. Documentation corrections, small reproducible examples and clearly scoped code changes are welcome.

## Report a problem

Search existing issues first. Include:

- Plugin version or commit, QGIS version and operating system.
- Input type, CRS, units, dimensions/feature count and relevant NoData settings.
- Exact steps and Processing parameters.
- Expected result, actual result and complete relevant Processing log.
- A small dataset you have permission to share, or instructions to reproduce it synthetically.

Remove confidential data, credentials and private file locations before posting.

## Suggest a feature

Describe the decision or task you need help with, your current workaround, and a concrete example of the desired output.

## Submit a change

1. Work on a branch and keep the change focused.
2. Explain the problem and resulting behavior in the pull request.
3. For documentation, check links and parameter names against the current implementation.
4. For code, run the affected workflow in QGIS and report your environment, inputs and results.
5. For numerical changes, compare against an independent reference or analytically known example and include edge cases.

If you could not run QGIS, state that clearly. Do not describe unexecuted checks as passing.
